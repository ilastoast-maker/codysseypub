# 🗂️ 나만의 프롬프트 관리 (Prompt Manager)

GenAI 미션에서 작성한 프롬프트를 한곳에서 관리하는 **Python 콘솔 프로그램**입니다. 프롬프트를 카테고리별로 분류하고 검색하며, 즐겨찾기·조회수·수정/삭제 기능을 사용할 수 있습니다. 추가로 JSON 저장/불러오기와 Markdown 내보내기를 지원합니다.

> 저장소: `ilastoast-maker/codysseypub`  
> 브랜치: `09a1`  
> 과제 폴더: `A1-1`

## 주요 기능

| 번호 | 기능 | 설명 |
|---:|---|---|
| 1 | 프롬프트 추가 | 제목, 내용, 카테고리를 입력해 새 프롬프트 등록 |
| 2 | 프롬프트 목록 | 전체 프롬프트와 원본 번호, 카테고리, 즐겨찾기 표시 |
| 3 | 카테고리별 조회 | 선택한 카테고리만 조회하며 전체 목록의 원본 번호 유지 |
| 4 | 프롬프트 검색 | 제목/내용 키워드 검색, 결과에서도 원본 번호 유지 |
| 5 | 프롬프트 상세 보기 | 전체 내용과 조회수 확인, 열람 시 조회수 +1 |
| 6 | 즐겨찾기 관리 | 전체 목록을 보고 정확한 번호로 즐겨찾기 추가/해제 |
| 7 | 즐겨찾기 목록 | 즐겨찾기만 표시하되 원본 프롬프트 번호 유지 |
| 8 | 프롬프트 수정 | 제목·내용·카테고리 수정 |
| 9 | 프롬프트 삭제 | 번호 선택 후 확인을 거쳐 삭제 |
| 10 | 인기 프롬프트 | 조회수 기준 Top 5 표시, 원본 번호 함께 제공 |
| 11 | JSON으로 저장 | 현재 데이터를 `prompts.json`에 저장 |
| 12 | JSON에서 불러오기 | JSON 구조 검증 후 안전하게 불러오기 |
| 13 | Markdown 내보내기 | `prompts_export.md` 생성, 사용자 지정 카테고리 포함 |
| 0 | 종료 | 프로그램 종료 |

## 등록된 기본 카테고리

`텍스트 생성`, `이미지 생성`, `영상 생성`, `페르소나`, `자동화`, `기타` 총 6개이며, 시작 시 각 카테고리에 기본 프롬프트가 1개씩 등록되어 있습니다.

## 이번 검토에서 수정한 핵심 문제

- 즐겨찾기 목록이 필터 결과에 다시 `1, 2, 3...` 번호를 붙이던 문제를 수정했습니다.
- 즐겨찾기 관리에서 선택 전에 전체 목록을 보여주고, 추가/해제된 항목명을 출력하도록 개선했습니다.
- 카테고리별 조회와 검색 결과에서도 **전체 프롬프트의 원본 번호**를 유지합니다.
- 상세 보기·수정·삭제에서 대상 선택 전에 전체 목록을 표시합니다.
- 삭제 취소 시 명확한 안내를 출력합니다.
- JSON 파일은 스크립트 위치 기준으로 저장/불러오며, 잘못된 JSON을 불러와도 기존 메모리 데이터를 지우지 않습니다.
- Markdown 내보내기에서 사용자가 직접 입력한 카테고리도 누락하지 않습니다.

## 개발 환경

- Python 3.10 이상 권장
- 외부 라이브러리 없음
- 테스트: Python 표준 라이브러리 `unittest`

## 실행 방법

```bash
git clone -b 09a1 https://github.com/ilastoast-maker/codysseypub.git
cd codysseypub/A1-1
python main.py
```

Windows에서 `python` 명령이 연결되지 않았다면 `py main.py`를 사용할 수 있습니다.

## 테스트 방법

전체 자동 테스트:

```bash
cd codysseypub/A1-1
python -m unittest discover -s tests -v
```

문법 검사:

```bash
python -m py_compile main.py tests/test_main.py
```

최종 검토 기준에서는 **15개 자동 테스트가 모두 통과**했습니다. 상세 결과는 `TEST_REPORT.md`를 확인하세요.

## 데이터 구조

각 프롬프트는 다음 형태의 딕셔너리로 관리합니다.

```python
{
    "title": "블로그 글 작성 도우미",
    "content": "프롬프트 내용",
    "category": "텍스트 생성",
    "favorite": True,
    "views": 0,
}
```

## Git 과제 확인

`09a1` 브랜치는 기능/데이터/문서 단위 커밋에 이번 버그 수정·테스트·문서화 커밋을 추가하여 **10개 이상의 의미 있는 커밋**을 유지합니다. 확인 명령은 다음과 같습니다.

```bash
git checkout 09a1
git log --oneline --graph
git rev-list --count HEAD
```

A1-1 관련 변경만 보고 싶다면:

```bash
git log --oneline -- A1-1
```

## 주의사항

- 프로그램 실행 중 변경한 데이터는 11번 **JSON으로 저장**을 실행해야 파일에 반영됩니다.
- 12번 불러오기는 `prompts.json`의 필수 필드(`title`, `content`, `category`)를 검증합니다.
- 조회 결과의 번호는 다른 메뉴에서 그대로 사용할 수 있도록 항상 원본 목록 번호를 유지합니다.
