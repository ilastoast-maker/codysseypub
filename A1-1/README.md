# 🗂️ 나만의 프롬프트 관리 (Prompt Manager)

GenAI 미션을 수행하며 쌓인 프롬프트를 한곳에서 체계적으로 관리하는 **Python 콘솔 프로그램**입니다.
카테고리 분류 · 키워드 검색 · 즐겨찾기 기능을 제공하며, Git으로 기능 단위 버전 관리를 실습하기 위해 만든 프로젝트입니다.

> "그때 그 프롬프트 어디 갔지?"를 끝내기 위한 나만의 프롬프트 집 🏠

> 저장소: `ilastoast-maker/codysseypub`  
> 브랜치: `09a1`  
> 과제 폴더: `A1-1`

## ✨ 주요 기능

| 번호 | 기능 | 설명 |
|------|------|------|
| 1 | 프롬프트 추가 | 제목·내용·카테고리를 입력해 새 프롬프트 등록 |
| 2 | 프롬프트 목록 | 저장된 모든 프롬프트 출력 |
| 3 | 카테고리별 조회 | 선택한 카테고리의 프롬프트만 조회 |
| 4 | 프롬프트 검색 | 제목 또는 내용 키워드 검색 |
| 5 | 프롬프트 상세 보기 | 제목·카테고리·즐겨찾기·내용·조회수 표시 |
| 6 | 즐겨찾기 관리 | 즐겨찾기 추가/해제 |
| 7 | 즐겨찾기 목록 | 즐겨찾기 프롬프트만 조회 |
| 8 | 프롬프트 수정 | 제목·내용·카테고리 수정 |
| 9 | 프롬프트 삭제 | 선택한 프롬프트 삭제 |
| 10 | 인기 프롬프트 | 조회수 기준 Top 5 |
| 11 | JSON으로 저장 | `prompts.json` 저장 |
| 12 | JSON에서 불러오기 | `prompts.json` 불러오기 |
| 13 | Markdown 내보내기 | `prompts_export.md` 생성 |
| 0 | 종료 | 프로그램 종료 |

## 📂 등록된 프롬프트 카테고리

프롬프트는 아래 **6개 카테고리**로 분류합니다.

| 카테고리 | 설명 |
|----------|------|
| 텍스트 생성 | 블로그·이메일·문서 등 글 작성용 |
| 이미지 생성 | 썸네일·일러스트 등 이미지 생성용 |
| 영상 생성 | 광고·숏폼 등 영상 제작용 |
| 페르소나 | 전문가·캐릭터 역할 부여용 |
| 자동화 | 요약·분류 등 반복 작업용 |
| 기타 | 위 분류에 속하지 않는 프롬프트 |

> 프로그램 시작 시 6개 카테고리에 기본 프롬프트가 1개씩, 총 6개 등록되어 있습니다.
