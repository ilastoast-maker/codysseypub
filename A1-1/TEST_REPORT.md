## 4. 발견 및 수정한 핵심 결함

### 즐겨찾기 번호 불일치

기존 구현은 즐겨찾기 목록을 필터링한 뒤 다시 1번부터 번호를 매겼습니다. 반면 즐겨찾기 관리 기능은 전체 `prompts` 목록의 번호를 사용했습니다. 따라서 즐겨찾기 목록에서 보이는 번호를 관리 기능에 입력하면 다른 프롬프트가 토글될 수 있었습니다.

수정: 필터된 조회에서도 전체 `prompts`의 **원본 번호를 유지**합니다.

### 동일 계열 문제

카테고리별 조회와 검색 결과에도 필터된 목록 번호가 새로 매겨질 수 있는 문제가 있었습니다.

수정: 카테고리·검색·즐겨찾기 모두 동일한 `show_indexed_subset()` 방식을 사용해 원본 번호를 유지합니다.

### JSON 안전성

잘못된 JSON을 불러올 때 현재 메모리 데이터를 먼저 지우면 데이터 손실 위험이 있습니다.

수정: 전체 JSON을 먼저 검증/정규화한 후 검증 성공 시에만 `prompts`를 교체합니다.

### 사용자 지정 카테고리 내보내기

기존 Markdown 내보내기는 미리 정의된 카테고리만 순회해 직접 입력한 카테고리가 누락될 수 있었습니다.

수정: 기본 카테고리에 없는 사용자 지정 카테고리도 동적으로 포함합니다.
