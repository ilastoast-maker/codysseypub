# 🗂️ 나만의 프롬프트 관리 (Prompt Manager)

GenAI 미션을 수행하며 쌓인 프롬프트를 한곳에서 체계적으로 관리하는 **Python 콘솔 프로그램**입니다.
카테고리 분류 · 키워드 검색 · 즐겨찾기 기능을 제공하며, Git으로 기능 단위 버전 관리를 실습하기 위해 만든 프로젝트입니다.

> "그때 그 프롬프트 어디 갔지?"를 끝내기 위한 나만의 프롬프트 집 🏠

## ✨ 주요 기능

| 번호 | 기능 | 설명 |
|------|------|------|
| 1 | 프롬프트 추가 | 제목·내용·카테고리를 입력해 새 프롬프트 등록 (빈 값 재입력) |
| 2 | 프롬프트 목록 | 저장된 모든 프롬프트를 번호·카테고리·즐겨찾기(⭐)와 함께 출력 |
| 3 | 카테고리별 조회 | 선택한 카테고리의 프롬프트만 모아 보기 |
| 4 | 프롬프트 검색 | 제목 또는 내용에 키워드가 포함된 프롬프트 검색 |
| 5 | 프롬프트 상세 보기 | 번호 입력 시 제목·카테고리·즐겨찾기·내용 전체 표시 |
| 6 | 즐겨찾기 관리 | 번호 입력으로 즐겨찾기 추가/해제 |
| 7 | 즐겨찾기 목록 | 즐겨찾기(⭐)된 프롬프트만 모아 보기 |
| 0 | 종료 | 프로그램 종료 |

### ⭐ 보너스 기능
| 번호 | 기능 | 설명 |
|------|------|------|
| 8 | 프롬프트 수정 | 기존 프롬프트의 제목·내용·카테고리 수정 (CRUD) |
| 9 | 프롬프트 삭제 | 번호 선택 후 확인을 거쳐 삭제 (CRUD) |
| 10 | 인기 프롬프트 | 상세 보기 조회수 기준 Top 5 정렬 출력 |
| 11 | JSON으로 저장 | 전체 프롬프트를 `prompts.json` 파일로 저장(영속화) |
| 12 | JSON에서 불러오기 | `prompts.json` 파일에서 프롬프트 불러오기 |
| 13 | Markdown 내보내기 | 카테고리별로 정리한 `prompts_export.md` 파일 생성 |

> 보너스 기능도 표준 라이브러리 `json`만 사용하며, 별도 외부 라이브러리가 필요 없습니다.
> 상세 보기(5번)를 실행하면 해당 프롬프트의 **조회수**가 1 증가합니다.

- 잘못된 번호를 입력하면 안내 메시지를 출력하고 다시 메뉴로 돌아갑니다.
- 실행 중 추가한 프롬프트와 즐겨찾기 상태는 유지되며, **프로그램 종료 시 초기화**됩니다.
- 모든 기능은 역할별 함수(`show_menu()`, `add_prompt()`, `show_list()`, `search_prompt()`, `show_favorites()` 등)로 분리되어 있습니다.

## 📂 등록된 프롬프트 카테고리

프롬프트는 아래 6개 카테고리로 분류합니다.

| 카테고리 | 설명 |
|----------|------|
| 텍스트 생성 | 블로그·이메일·문서 등 글 작성용 프롬프트 |
| 이미지 생성 | 썸네일·일러스트 등 이미지 생성용 키워드 프롬프트 |
| 영상 생성 | 광고·숏폼 스크립트 등 영상 제작용 프롬프트 |
| 페르소나 | 특정 전문가·캐릭터 역할을 부여하는 페르소나 설계 프롬프트 |
| 자동화 | 요약·분류 등 반복 작업 자동화용 프롬프트 |
| 기타 | 위 분류에 속하지 않는 프롬프트 |

> 프로그램 시작 시, 이전 미션에서 작성한 프롬프트가 **기본 데이터로 3개 이상** 등록되어 있습니다.

### 데이터 구조 예시
```python
prompts = [
    {
        "title": "블로그 글 작성 도우미",
        "content": "당신은 10년 경력의 전문 블로거입니다...",
        "category": "텍스트 생성",
        "favorite": True
    },
    ...
]
```

## ▶️ 실행 방법

1. 저장소를 클론합니다.
   ```bash
   git clone https://github.com/<사용자명>/prompt-manager.git
   cd prompt-manager
   ```
2. 프로그램을 실행합니다.
   ```bash
   python main.py
   ```
3. 메뉴가 출력되면 원하는 기능의 번호를 입력합니다.
   ```
   === 나만의 프롬프트 관리 ===
   1. 프롬프트 추가
   2. 프롬프트 목록
   3. 카테고리별 조회
   4. 프롬프트 검색
   5. 프롬프트 상세 보기
   6. 즐겨찾기 관리
   7. 즐겨찾기 목록
   0. 종료
   선택:
   ```
